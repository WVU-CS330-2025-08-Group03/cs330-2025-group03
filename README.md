# LiveWise

LiveWise is a home and city discovery platform designed to help people explore neighborhoods, compare living conditions, and make smarter relocation decisions. The app combines home-search style browsing with neighborhood data such as school quality, cost of living, safety, population, and location-based information so users can better understand where they want to live.

## What it does

LiveWise lets users:

- Search for cities and neighborhoods using filters like population, crime rate, school ratings, and affordability
- Compare different areas based on quality-of-life factors
- Save favorite cities or preferred areas for later review
- Create an account and access a personalized dashboard
- Explore a home-buying style interface centered around finding a place that fits their lifestyle and budget

The project is built as a full-stack web application with a React frontend and a Node.js backend, and it is geared toward helping users evaluate places to live before making a major decision.

## Project overview

This repository contains the LiveWise application code for both the user interface and the backend services that power city data, user accounts, favorites, and search functionality.

## Important note

The original LiveWise server is no longer active and is not currently being hosted or maintained. This repository is kept here for project reference, development, and local testing purposes.

If you want to continue working on the project, you can run the frontend and backend locally from this codebase.
